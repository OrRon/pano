what it does

▾Decrypts HTTPS

HTTP/1.1, HTTP/2, WebSocket, SSE. Your CA decides: all, only a list, or never.

◆Understands LLM traffic

Anthropic, OpenAI and Gemini streams reassembled: final text, tool calls, token usage.

⚡︎Agent-driven chaos

Latency, failure rates, mocks, holds. Every rule can expire on its own.

·Token-efficient

One line per flow. Summaries before bodies. A path into any payload.

◇A TUI that doesn't look like one

pano ui: live list, explain, diff, rules. Designed, not default.

○Fast and forgetful

One static Go binary. Everything in memory. Every start is empty.

safety

Built like it knows it's a man-in-the-middle.

your CA, yours alone
Generated on your machine, for your user. TLS trust only. Valid 2 years, not 10.
terminal only
Trusting the CA and turning pano on have no MCP equivalent. The password prompt is yours.
secrets redacted
Keys, cookies and tokens masked in every view. Revealing is explicit, per call, audited.
loopback only
Never root. Quitting restores your proxy settings, even after a crash.
no phoning home
One notify-only release check a day, off with DO_NOT_TRACK=1. pano never updates itself.
quickstart · 60 seconds
1
brew install orron/tap/pano
pano ca install      # one-time: trust the local CA
2
pano on              # route the Mac through pano · q quits & restores
3
pano mcp install     # adds the MCP server to Claude Code

Then ask your agent: "is pano on?"
